Hurricane on, Cyclone Armor up, Lightning Storm into packs from range. Wind Shear when Spirit runs out. Stay at range - the whole reason for this build is not being in melee.

How to run them

Raheir hired with Ground Slam, Bastion, Iron Wolf's Virtue and Raheir's Aegis, exactly as every Shred Druid profile does - Valiance's cheat-death is not something a Druid gives up this season. The reinforcement is where this build reasons differently from the meta one. The meta build takes Varyana for Bloodthirst attack speed because it wins by clicking Shred faster; this build has no attack-speed scaling at all, since Lightning Storm and Hurricane tick on their own timers. So the attack speed is close to worthless here and Aldkin's Field of Languish - flat area damage reduction on a build that stands still and channels - is the better trade. That reasoning is the specialist's; the pairing itself is one Maxroll and Icy Veins both endorse for Druid.

Plan

Adapted from the Shred Druid's published tree, which is the closest real source - and the adaptation matters, because this build's gearing is genuinely different. It does not need Ifeh's Dire Totem, which exists to enable Shred inside Grizzly Rage, so the Lair Boss tree is worth less here than it is to the meta build. What it does need is paragon levels, because every Spirit-regeneration node is a damage node under the Berú set. So the weighting moves toward Kurast Undercity and The Pit. The Hardcore warning carries over unchanged: avoid Cult of Annihilation.

Summary

UNTESTED - original theorycraft built as deliberate insurance rather than as a damage maximiser. The meta Shred build is excellent right now but rests on two things Maxroll itself flags as bugs: the Storm Shepherd set's dominance is partly attributed to bugs, and clicking Shred rather than holding it re-triggers the Waxing Gibbous 2-set bonus, which Maxroll calls a mechanical exploit. Exploits get patched. The question this build asks is whether the durable part of the Druid meta - the Berú of the Storm Shepherd rule that damage scales with Spirit regeneration rate - can be harvested by a Storm skill that does not depend on the Shred click interaction at all. Lightning Storm is the candidate: Icy Veins independently rates it S tier, it is already in the meta build's own skill bar as an Orange Herald trigger, and it is a ranged toggle, which also sidesteps Druid's named survivability weakness. If the Shred interaction is patched, this build should be roughly unaffected; if it is not, this build is probably a modest downgrade. That trade is the entire point.

Reasoning

HypothesisThe Berú of the Storm Shepherd set bonus scales damage with Spirit regeneration rate, and that scaling is a property of the set rather than of Shred specifically. Therefore a Lightning Storm build stacking the same Spirit regeneration sources should capture most of the same scaling while depending on none of the Shred-specific interactions that Maxroll flags as bugged - making it materially more durable across patches, at some cost in peak damage.
Confidencemedium
How to test itTest one: confirm the premise before anything else. Equip Berú of the Storm Shepherd, note your Spirit regeneration rate, then add a single large regen source and check whether Lightning Storm's tooltip or practical damage moves proportionally the way Shred's does. If the set bonus turns out to be Werewolf-gated or Shred-gated in practice, this build has no engine and should be abandoned immediately - that is the single highest-risk assumption here. Test two: compare a Pit clear against druid-meta-shred at identical gear quality; expect to be somewhat slower, and treat anything within a tier or two as success given the durability goal. Test three: deaths per run. This build's secondary claim is that a ranged toggle build survives better than a melee Werewolf build in a class whose survivability is a documented weakness, so count deaths, not just clear time. Test four - the one that actually matters - re-run all of the above after the next balance patch. If the Shred click interaction gets fixed and this build's numbers barely move while the meta build's drop, the thesis is confirmed. Also watch whether Hurricane alone provides enough Spirit regeneration without Shred's attack cadence feeding it, since much of the meta build's regen comes from being in melee constantly.
